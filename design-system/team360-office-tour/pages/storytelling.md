# KAZ Software Anniversary Tour 2026 — Design Overrides

UI/UX Pro Max generated a base system; for this Bengali cinematic storytelling presentation we override:

## Style
- Pattern: Scroll-Triggered Storytelling + Bento destination cards
- Visual: Editorial cinematic (deep forest ink + warm amber), not Aurora/pink editorial
- Avoid: purple gradients, glassmorphism overload, emoji-as-icons, cream+terracotta AI cliché

## Colors (presentation / projector)
| Role | Hex |
|------|-----|
| Background | `#0A1210` |
| Surface | `#13201C` |
| Paper (light panels) | `#F3F6F4` |
| Foreground on dark | `#F2EFE8` |
| Foreground on light | `#0B1F1A` |
| Primary (teal) | `#2A9D8F` |
| Accent (amber) | `#E9B44C` |
| Muted | `#8BA39A` |
| Danger soft | `#E07A5F` |

## Typography (Bengali-capable)
- Display / headings: `Noto Serif Bengali`
- UI / body: `Hind Siliguri`
- Numerals / labels: `Outfit` (Latin only for EN labels if any)

## Motion
- 180–280ms transitions
- IntersectionObserver reveals
- Honor `prefers-reduced-motion`
- Max 1–2 key motions per viewport

## Content
- 4 unique destinations (Sajek listed twice in brief)
- No budget / cost / ranking / winner
- Fictional office humor marked clearly vs factual info
- Language: Bangla throughout
